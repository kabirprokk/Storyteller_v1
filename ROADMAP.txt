------------------------------------------------------------
1. WHAT THIS WEBSITE IS
------------------------------------------------------------

Storyteller is a cinematic reading and writing platform.

It lets users:
- read published stories
- create Reader or Writer accounts
- write and publish stories
- save drafts
- like stories
- bookmark stories
- comment on stories
- follow writers
- report stories
- manage profiles
- use admin/moderation tools

The website is built with:
- HTML
- CSS
- vanilla JavaScript
- Supabase Auth
- Supabase Postgres database
- Supabase Storage
- Supabase Edge Functions
- Netlify hosting

There is no build framework like React, Vite, Next.js, or WordPress.

--- View count improvement ---

Commit: 3bcc711
Title: Improve story view counting

Changes:
- View count now waits about 3.5 seconds before counting.
- Prevents duplicate count requests in the same browser for the same story/hour.
- Updates visible story view count immediately if Supabase confirms it counted.
- Supabase Edge Function fingerprint now uses:
  - IP
  - user agent
  - browser language
  - secret salt

Reason:
The previous view count could feel unreliable and could collapse multiple people on the same network into one view.

Important deployment note:
Netlify deploys frontend automatically, but Supabase Edge Functions do not auto-deploy from Netlify.
Run this after changing Supabase function code:

supabase functions deploy record-story-view --no-verify-jwt

If custom domain is added later, update Supabase Edge Function secret:

ALLOWED_ORIGINS=https://storyteller-v1.netlify.app,https://yourdomain.com

- Preserves:

  - active page

6. SUPABASE NOTES
------------------------------------------------------------

Public frontend config:
js/config.js

This contains:
- Supabase URL
- Supabase publishable key

Never put these in browser code:
- service_role key
- database password
- private tokens
- Supabase secrets

For view counter Edge Function deploy:

supabase functions deploy record-story-view --no-verify-jwt

Required Supabase Edge Function secrets:
- VIEW_COUNT_SALT
- ALLOWED_ORIGINS

Current origin:
https://storyteller-v1.netlify.app

Future custom domain should be added to ALLOWED_ORIGINS.
